# 一颗毛球惹的祸 · AI 片头制作包

本轮按用户要求，把 30 秒程序化片头改作动画骨架，用定妆图和重绘首帧驱动 4090 生成。现有程序版保留在 `scenes/rongboy-intro/`；本包属于同一故事的 AI 画面试验。用户未采用，现已搁置，游戏菜单已撤下片头入口。

## 视觉基准

采用原版绒仔和第一只跳跳的身份与衣装。材质朝实拍针毡布偶靠拢：看得见短羊毛、蓬松边缘、布片、缝线、填棉体积和接触阴影。暖蜂蜜色侧光、冷青窗外、木地板和桃色沙发延续原舞台。

- 绒仔：燕麦肤色、黑珠眼、栗色发束、圆护目镜探险帽、芥末围巾、帆布外套、鼠尾草背包和燕麦色卷毯。
- 跳跳：原版椭圆鼠尾草绿脑袋，大小不同的双叉线纽扣眼、补丁额头、歪布牙、棕背心和紫色补丁长裤。
- 炸弹客：小头、宽圆躯干、短腿；手里实际托住毛线炸弹和短引线。
- 弓手：细长身躯、长梨形脑袋；弓身、弦、箭杆、软箭头、尾羽都能辨认。

`cast/` 是定妆候选，`firstframes/*_paint_master.png` 是生图原始输出；`*_paint.png` 仅作 1024×576 Lanczos 缩放，提供给视频模型。候选图已内部检查，不代表用户已确认。

## 镜头与生成

`shot-plan.json` 锁定 11 镜、24fps、720 帧、30 秒。`firstframes/*_source.png`、`guides/sNN.mp4` 来自程序化骨架，移除片名并修正了两个参考机位。反弹主镜头另有 `guides/s06-v2.mp4`，使用更正面的机位并将两碰点抬至 y=1.31m，避免原先的头部/柜子遮挡；只改变临时参考，原程序版不被覆盖。`jobs/` 是实际视频提示词；`look-prompts-batch*.json` 保存了 s03–s11 的原始生图请求；`anchor-prompts.json` 另存新增关键帧的实际请求。绒仔/跳跳/炸弹客/弓手及 s01/s02 的生图请求未逐字归档，不能把本页风格概述当作其逐字请求。

使用既有 `shouyun-4090` ComfyUI 影刺 F 工作流：H3 FL2VA fp8 + FL2V Turbo 8-step LoRA，8 步，res_multistep/simple，24fps，原生 1024×576。角色图通过 reference conditioning、首帧通过 frame-0 guide、程序动画通过 video guide 输入。关键镜头用项目内 `h3run-multiguide.py` 追加准确原生帧索引的图像：s06=44/56/138（门框/右墙/落座），s09=72（横移终点）。该节点实际支持任意像素帧和多节点串接；源码快照和参数都保留。`runtime-snapshot/` 是已实际运行的远端程序快照，**本地旧 h3run.py 不具备同一补丁，不能覆盖远端**。

只使用提交前 running 和 pending 队列都为空的既有实例，不安装模型、不重启服务、不清缓存。`receipts/` 和 `runs/` 保留每次提交、prompt ID、输入散列、队列检查和原始结果；提交结果不确定时不得盲目重试。

s05 以 2.2 倍慢动作生成，s06 以 2 倍慢动作生成，再按时间线还原；模型原生帧数向上取整，仅截掉尾部多余帧。`selection.json` 指定入剪片，`edit-overrides.json` 记录额外修剪及原因，不改写原片。

## 合成与复现

最终视频：`scenes/rongboy-intro/ai/rongboy-intro-ai-v1.mp4`。

保留每条原生 MP4，全部静音后按目标帧数拼接。音乐与拟音复用程序版原创合成器：音乐与主体音效相同，落座提示按实际画面改到14.67秒，弓弦/毛线两处提示按弓手→炸弹客的硬切调整到21.65/22.65秒，29.25秒补一声轻布空气声。`retime-score.py` 只导入原 `score.py` 并使用新 cue-map，不复制合成器；片名 `RONGBOY / 一颗毛球惹的祸` 在后期精确排字，26–30 秒显示。交付是 Lanczos 放大至 1920×1080，**不是原生 1080p 视频生成**，未添加生成细节或插帧。

在制作包目录运行（Python Pillow、ffmpeg/ffprobe）：

```sh
python3 assemble.py --score sound/out/mix.wav --out ../../../scenes/rongboy-intro/ai
```

`sound/out/mix.wav` 保留为无损音轨；若要重建，按程序版 `score.py` 的依赖说明运行本包 `retime-score.py`。片名使用 macOS Georgia Bold 和 Songti，未分发字体文件。原生片和回执可直接复核，不必重跑 GPU 任务。任务脚本带有本次主机/项目路径，仅作制作证据；重新提交前应明确新的项目前缀和任务边界。

验收包含全片解码、30 秒/720 帧、关键动作密集抽帧、跨镜角色/毛球/枪口/房间连续性，以及声音和片名检查。自动检测不能代替可读性和观感审阅。具体发现见交付目录 `QA.md`。s09最终保留原生前段0–26和后段52–72帧，连续减速后各占36帧，以一次明确硬切避开横移时的复制变形；因此成片为12个剪辑镜头，仍对应11段程序动作参考。末镜保留了模型生成的向镜头投弹动作，作为入战收尾。
