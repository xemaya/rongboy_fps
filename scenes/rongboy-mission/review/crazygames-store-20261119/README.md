# CrazyGames 封面与实机预览候选

| 封面 | 画面重点 |
|---|---|
| A | 绒仔在左边，亮色花园里的毛球从青色墙板弹向跳跳 |
| B | 纽扣眼僵尸和快贴到脸上的毛球，黄昏侧光突出毛毡纤维 |
| C | 第一人称枪口、墙面和僵尸组成一眼可读的反弹路线 |

候选封面参照现有绒仔手办、跳跳手办和花园场景，使用内置 imagegen 制作。提示词存于 `cover-prompts.json`。

## 实机镜头

横竖各 476 帧，30 fps，15.87 秒。本地从 CrazyGames HTML5 发布包打开 Chrome，按画幅分别录制，使用游戏原有准星、弹药、毛球、命中动画和场景光照。各段从摆好的实机关卡站位开始，保持正常游戏速度。视频无音轨。

| 时间 | 镜头 |
|---|---|
| 0.00–2.60 s | 花园手枪开火，毛球撞青色墙板后打倒跳跳 |
| 2.60–6.40 s | 学校颜料桶被打翻，颜料飞溅并伤到近处的僵尸 |
| 6.40–10.10 s | 博物馆聚光灯亮起，照住僵尸后补射 |
| 10.10–15.87 s | 实机试战的守墓巨像与探照灯炮 |

花园两版都核对了射弹记录。同一颗毛球先碰撞 `garden-sewing-board`，再命中并击倒跳跳，造成 6 点伤害。横版是 1920×1080，竖版是 1080×1620，两个文件都小于平台的 50 MB 上限。

## B 版送审素材

已选 B 版僵尸特写。横版按原构图输出，竖版和方版使用内置 imagegen 参照同一张原图重排，保留纽扣眼、脸颊旁的毛球和布绣标题。

[送审素材](submission/)内有三张 PNG 封面（1920×1080、800×1200、800×800）和两支 MP4 预览。两支视频各 477 帧、15.90 秒、无音轨。第一帧为对应封面，仅占一帧，接原评审版全部 476 帧实机画面。第一段实机动作是弹墙击倒。 [CrazyGames 素材规格](https://docs.crazygames.com/requirements/game-covers/)
