# 绒木镇 · 八关 Boss 设定

依据 [《绒木镇的僵线危机》](../worldview.md) 的八关顺序和专属武器。这轮是美术及战斗设计评审稿。已有定稿的守墓巨像和噬连兽保留体型；小丑以游乐场样板的面具、惊喜盒与四种招式为起点。

## 八关总览

|---|---|---|

## 打样优先 · 嬉笑小丑

[帐篷内的四格实机机位分镜](09-giggles-fight.jpg)

**进场。** 帐篷只亮中央一盏顶灯。垂下的幕布露出礼盒，小丑从盒里弹到圆台上，站起来时让第一人称镜头一下看清高处的笑脸、面具搭扣与近处惊喜盒的距离。

**戴面具。** 先教学一次完整的盒子节奏。飞来的盒子落地前给一圈提示，直接落到绒仔身上会把他短暂封住，再弹出并扣血。安全落地的盒子弹簧外露，方盖有稳定的踩踏面。第一箱落点留在小丑正前方，弹起时面具在视线中央附近。地面射击会弹开，腾空打中时面具边上的缝扣会崩开，配一声短促裂响。

**面具裂开。** 面具碎片和被压扁的棉絮飞开，露出连接在身上的绿毡脸与两颗纽扣眼。布偶踉跄扶帽，给玩家第一段明显的输出时间。后续用这四种动作轮换，同一时刻只铺一种主要预警。

| 招式 | 抬手预告 | 玩家应对 |
|---|---|---|
| 惊喜盒 | 小丑举三只盒，落点依次闪烁 | 移出落点，等稳定的盒盖掀开，利用它弹跳。 |
| 杂耍球 | 三组绒球在两只手之间依次升高 | 看清三轮来向，横移，或让开正面射线。 |
| 烟花 | 小丑指向帐顶，烟花绒线先上升，着地点再闪烁 | 走出落点再开枪，保留移动空间。 |
| 地板消失 | 抽走地板前，砖边先内缩、角缝亮起 | 移到稳固地砖。急冻射线是额外保险，原生跳跃也可躲。跌落扣血并回到安全垫。 |

**收尾。** 小丑倒地时灰僵线从衣缝松开，露出安静的布偶脸，帐篷和园区彩灯依次重亮。从礼盒底部露出高压马达，接回工作坊和下一关的静电飞网枪。

打样的人试玩时先验证三件事：第一次遇到的人能不能认出安全盒；弹到最高处时能不能在视野里找到脸；破面具后的地板预警有没有盖住脚下可走区域。冻结、地砖和高压马达属于新版设定，实机实现另行验收。

## 无尽破坏者 · 三阶段剪影

- **河豚。** 缝合刺球先吸气，外皮箍紧时线核隐去，随后滚撞或抛出软头针刺。吸气时用探照灯炮，泄气后的腹部会露出线核。玩家主要练习横向躲开滚动路线。
- **章鱼。** 刺球的布层沿接缝翻出八条触手。抬起的触手先投下长影，落地后留下可通行的扇区。探照灯炮打断吸附，触手缩回并显露中央线核。噬连兽的吸盘规则可以作为原型，画面保持多臂占地的差异。
- **蛇。** 八股触手收束成一条带绣纹的长背。钻入时沿地板留下连续缝线亮点，昂首时七寸的线核浮到表面。探照灯炮驱散局部僵雾，给一次清楚的射击窗口。结束后，线核散成彩色线头，回接全镇苏醒。

造型以现有针毡布偶为材质基准。三视图用于确定轮廓、部件与配色，建模时按同一实际尺寸校对头颈接缝、手持部件和可动关节。八关的攻击细化与弱点位置均为本轮提案，数值与可达性须由实机确定。
