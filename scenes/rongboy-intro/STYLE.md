# Rongboy · 原生针毡动作喜剧

- 基准：原 V2 绒仔/跳跳与 V5 炸弹客/弓手，原网格、颜色、纤维与布口保留。
- 光：暖奶油室内、蓝绿窗外，侧光与接触阴影让针毡可读；稳定曝光。
- 场：调用 cine-engine 的 plushMaterials、PlushKit、沙发、窗、柜和地毯，紧凑客厅舞台。
- 镜头：以角色眼高和全身中景为主，装填用近景；反弹为完整主镜头；固定机位里清晰演出，结尾匹配到第一人称。
- 动画：身体有蓄势、动作、回弹；相机连续，角色可以有轻微布偶式停顿；手持物与手掌对齐。
- 音乐：原作玩具钟琴、木质拨弦和软质打击，无对白；两个近静音段。
- 字：RONGBOY 为游戏已有品牌，中文副题「一颗毛球惹的祸」；26–30 秒保持可读。
- 输出：1920×1080、24fps、30 秒。交互预览使用空格播放/暂停、R 重播、Enter 进入游戏。
