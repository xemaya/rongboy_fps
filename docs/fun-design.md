# 玩法准则：从"可玩"到"好玩"

核心用户是轻度休闲玩家。这份准则先于代码：改玩法前先看这里，改完把学到的写回第 7 节。
数值的当前取值在 `scenes/rongboy-mission/game.js`，实测表在 `scripts/tests/rongboy-fun.mjs`（跑一遍会打印）。

## 1. 一句话

**僵尸出题，枪是答案。** 每种僵尸只有一招，看外形就知道是哪招；每把枪只管一件事。玩家要做的决定只有两个：现在该用哪把枪，现在该站在哪。

## 2. 僵尸

2.1 **一种一招。** 不给单只僵尸叠第二种攻击。想要更难，靠种类的搭配和数量，不靠把某一只做复杂。
（《花园战争》的普通僵尸只会走过来打一下、偶尔扔块石头；差异全在外形上：普通 30 血、路障头约 127、铁桶头 170、纱门 400、爆炸小鬼 12 血。）

2.2 **看外形就知道。** 招式必须挂在看得见的东西上：弓、盾、手里举着的炸弹、一身棉甲。头顶的字只是补充，不能是唯一的提示。

2.3 **每一招都惩罚一种偷懒的打法，并且有一眼能看懂的躲法。**

| 僵尸 | 它的一招 | 惩罚的偷懒 | 躲法 | 最合适的枪 |
|---|---|---|---|---|
| 跳跳 | 走过来碰你 | 站着不动 | 拉开距离 | 什么都行 |
| 跃行者 | 蓄一下再扑一大段 | 以为隔得远就安全 | 看到金圈侧移，或开枪打断 | 霰弹（落到脸上时一枪倒） |
| 棉甲 | 正面只吃一半伤害 | 只会对着正面打 | 绕到背后 | 毛衣针（扎穿棉甲） |
| 弓手 | 远处拉弓射箭 | 一直后退、一直朝一个方向走 | 瞄准线变红以后换方向，或躲到掩体后 | 毛衣针（够得着）、静电枪（定住） |
| 炸弹客 | 往你脚下扔炸弹 | 站桩、躲在一个角落里 | 离开红圈 | 订书机枪、手枪（举弹时一打就断） |
| 持盾者 | 正面挡住普通毛球，蓄势后盾冲 | 只用手枪点射 | 绕后、反弹，或让开冲线 | 探照灯炮（一炮破防） |

2.4 **一次只教一种。** 新种类第一次出场要单独出现、给足空间；之后才和别的混在一起。（《花园战争》一局十波，第 2、4、6、8 波各加一种。）家这张图：花园和一层出弓手，二层加炸弹客，阁楼加持盾者。

2.5 **休闲玩家的保险。**
- 每次挨打只掉一颗心，之后 1.2 秒无敌。
- 远程攻击（箭、炸弹）同一时刻只有一只在出手，两次出手之间至少隔 0.9 秒。
- 远程攻击和盾冲出手前有不少于 0.9 秒的预告；箭和炸弹飞得慢、看得见。（跃行者的扑击只蓄 0.48 秒，但最多扑 3.8 米，挨一枪就断。）
- 弓手的瞄准线先跟着你走，出手前 0.35 秒定住变红：红了以后换方向、停下都躲得开。它算足了提前量，所以"一直朝一个方向走"和"直线后退"都会中箭。
- 远程和范围攻击都穿不过墙：掩体永远有用。
- 僵尸数量固定，不补充。

## 3. 枪

3.1 **手里两把，一键切换。** 手枪固定（备弹无限，永远不会没枪用），另一把可换；手雷不占手，单独一个键。
两把枪的限制只有在"僵尸对不同的枪反应不同"时才是选择，否则只是麻烦（Halo 1 成立的条件：敌人对武器反应不同、武器分工明确、弹药紧、敌人组合大致可预期）。所以第 2 节和这一节必须一起成立。

3.2 **手枪：什么都能打，什么都不是最快的。** 检查项：对每一种僵尸，手枪都打得倒；但没有任何一种僵尸是手枪打得最快的。

3.3 **每把特殊枪只管一件事，并且在那件事上明显比手枪强（至少快一倍，或者手枪根本做不到）。**

| 枪 | 管的事 | 代价 |
|---|---|---|
| 线轴手枪 | 兜底；蓄力球能破盾 | 慢 |
| 绒球霰弹 | 贴脸一枪倒 | 4 米外没用，两发就要换弹 |
| 探照灯炮 | 破盾、打断、把一只撞进一群里 | 一发一装，弹少，最吵 |
| 静电枪 | 飞行中张开的电网定住一小群，争取时间 | 飞网受掩体阻隔，伤害低 |
| 订书机枪 | 持续火力，清一群小的 | 有散布，吃弹药 |
| 毛衣针 | 4× 瞄准，扎穿棉甲、穿一排 | 要瞄，装得慢 |
| 弹簧小丑盒 | 一次范围伤害，猛地把僵尸顶散 | 数量少 |
| 折叠蒸笼 | 展开造成一次范围伤害，留下可绊脚的绒网 | 绒网只减速，新进来的敌人不会再吃一次伤害 |

3.4 **弹药不记种类。** 地上的弹药包补的是"你手里那把特殊枪"。捡到手里没有的枪要按键才换，不自动换：换枪是决定，不是意外。

3.5 **空弹匣有备弹就自动换弹，时间照常消耗。** 打空和切换到空弹匣都会开始换弹；装填完成前不能射击。切走会中断换弹，切回空枪重新计时，不能用切枪跳过装填。有弹的枪不因切换被强制换弹。特殊枪连备弹也用完时，沿用自动回到保底手枪的规则。

3.6 **"打不动"要成对出现。** 一把枪对某种僵尸没用（小纽扣打不动棉甲的正面、6 米外的手枪球断不了拉弓），就必须有另一把枪对它特别好用，而且要当场告诉玩家（"棉甲挡住了"）。只有前一半就成了卡关。

## 4. 受伤

4.1 **一次挨打要回答三个问题：我挨打了吗、从哪边来的、我还剩多少。** 分别对应：整屏边缘的红光；挨打那一侧更亮的光加一段指向来源的弧；碎掉的那颗心和只剩一颗心时持续的脉动。

4.2 **颜色要和场景反着来。** 这个游戏是暖色的（米、棕、绿），所以受伤用偏冷的玫红，不用土黄。

4.3 **不靠晃镜头。** 镜头只朝挨打的反方向轻轻偏一下，0.4 秒内回正；不加大抖动（用户会晕）。信息放在屏幕边缘，不遮准星。

4.4 **贴合题材。** 绒仔是布偶：挨打时从那一侧飞出几团棉絮，不出血。

## 5. 操作

键盘优先，也能用手柄（PS5 DualSense 走标准映射）。一个动作一个键，不用组合键。

- **键盘**：左手 WASD 走、Shift 蹦一下、Q 换枪、G 切换炸弹、E 投掷、R 换弹、F 捡枪；右手方向键转向；空格开火。
- **手柄**：左摇杆走、右摇杆转向 / 抬头低头；R2 开火（按住蓄力）、L2 投掷（按住扔得更远）、十字键下切换炸弹、R1 换弹、L1 换枪、□ 捡地上的枪、✕ 蹦一下、十字键左右直接选手枪 / 另一把、Options 暂停、✕ 确定 / 继续、○ 返回选图。
- 两套输入同时可用；屏幕上的按键提示跟着最近用过的设备换。摇杆和扳机是模拟量：轻推走得慢，扳机按住多久就蓄多久。
- **跳只是毛绒玩具蹦一下**：镜头离地约 0.4 米，不替代现有的枪和走位，不给无敌帧，也不改挨打判定；空中的枪口会跟着抬高。想要躲攻击，还是按每种僵尸的躲法来（侧移、掩体、打断）。
- 结算页：Enter / ✕ 再来一次，Esc / ○ 返回选图；暂停面板里 Enter / ✕ 继续、R / R1 重开、○ 返回选图。
- 浏览器不把"按手柄"当成用户操作：只用手柄开的局，声音可能要先按一下键盘或点一下画面才出来。页面会用一行提示说明，不假装声音已经开了。

## 6. 检查

改完跑 `node scripts/tests/rongboy-fun.mjs`：
- **枪表**：每把枪对每种僵尸从发现到击倒要几秒；断言 3.2 和 3.3。
- **偷懒的机器人**：只会后退加手枪。对只有贴身僵尸的阵容它能无伤打完（这就是改之前"无脑打"的原因）；对有弓手、炸弹客、持盾者的阵容它过不了。
- **留神的机器人**：看到瞄准线变红就换方向、离开红圈、对盾用蓄力球。同一个阵容它能过。说明难度来自"要不要看"，不来自手速。

机器人证明不了好玩，只能证明"偷懒不行、留神可以"。好不好玩要人玩。

## 9. 机关、暗格和布景反应

僵尸出题，枪是答案；机关是第三种答案：**这个房间本身能帮你**。它不能变成新的题，所以规矩比枪还紧。

9.1 **只用一个已有的动作触发：朝它打一球。** 不加新按键，不用走过去按。瞄准道具本身即可。架在头顶的晒被绳稍抬枪口就打得到。

9.2 **一种机关只有一个效果，而且是玩家已经见过的效果。** 闹钟引走未警觉的僵尸，颜料桶沿用范围伤害和缠绕减速，聚光灯和晒被绳沿用短暂定身。灯光、颜料和棉被的反馈分别做。

9.3 **只帮玩家。** 僵尸不会用机关，机关也不伤玩家（颜料桶和手雷一样只会把站太近的玩家推一下）。会伤到玩家的陷阱要多解释一条规则，先不做。

9.4 **四张正式地图各五件彩蛋。** 一件能影响战斗，四件提供独有的画面和声音。每件只摆一个点，两个放在顺路的位置，其余留给探索。道具本身和命中反馈负责传达用途，全部错过也可以按原任务过关。

| 地图 | 机关 | 命中反馈 | 生效范围 |
|---|---|---|---|
| 家 | 闹钟 | 响起来，9 米内还没在追你的僵尸走过去围着看，只盯着闹钟：贴到跟前、在旁边开枪或者打中它才回过神 | 隔着墙减半，和枪声一样 |
| 学校 | 颜料桶 | 炸开：2.6 米内掉血、被推开、走不快 | 墙和高家具挡得住 |
| 博物馆 | 聚光灯 | 暖光照向地面，被照到的僵尸短暂停住 | 约 3.2 米，墙和高家具挡得住 |
| 奶奶家 | 晒被绳 | 木夹松开，棉被落下，罩住下方的僵尸约 2 秒 | 落下时以被子下方的窄带判定 |

9.5 **战斗机关每局触发一次。** 用过后保持倒下、用尽或熄灯的状态。纯布景彩蛋可以重复触发，当前动作播完即可再打。

9.6 **机关旁边要有僵尸会经过。** 生效范围里没有僵尸、也没有僵尸会走过来的机关等于白放（地图的体检会查）。

9.7 **拉链暗格。** 墙上一条拉链，拉头会晃；打一下拉开，里面的补给掉到墙脚。不带文字，是给多看一眼的人的小奖励。三张图都有，每张两三处，里面只放补给（心、弹药包、毛线团），不放过关必需的东西。

9.8 **布景被打到要有反应，但反应不改规则。** 这是个布偶和玩具的世界：家具被毛球打中冒一团它那种颜色的绒絮，声音听得出是木头、软垫、玻璃还是金属；吊灯会晃、地球仪会转、小黄鸭会跳、盆栽会晃、骨架模型会抖。这些都只是画面和声音：不惊动僵尸、不挡球、不给分。玩家手枪的弹药是无限的，随手打一下有回应，本身就是乐趣（Astro Bot 的做法：先把互动做得好玩）。

## 10. 首领（守墓巨像）

10.1 **它是一个瞬间，不是一场要打赢的仗。** 开场片结尾：绒仔拿到毛线篮，身后的黑暗里亮起两只眼睛。游戏里就是这一刻：在"家"的阁楼拿起篮子，它在你身后现身。任务不变，还是把篮子带回院门；它不用打倒。

10.2 **现身之前它不存在。** 打不到、看不见、不算在僵尸数里。所以前面的潜行和清场不会被它打乱，也不会有人在拿篮子之前绕过去偷袭它。

10.3 **先给时间看清，再开始追。** 现身的 1.8 秒里它站着不动：先只有两只眼睛，眨一下，身子才出来。出现的位置在它自己够不着玩家的地方，而且不在任何一个出口前面。

10.4 **跑得掉，而且看得出跑得掉。** 阁楼版追击为 1.58 米/秒，玩家 3.15 米/秒。身体比楼梯宽，下不了楼。拿到篮子后，任务栏明确写着要把篮子带回院门，现身提示提醒躲开震地。实测走最短撤离路线可以避开巨像。

10.5 **两招都能读出来。** 阁楼版 44 点生命，震地蓄 1.3 秒，半径 4.05 米，招式间隔 2.4 秒。第一次震地后就能召援。圈线使用实际攻击半径。探照灯炮能打断，毛衣针可穿甲，绕后也有效。练习版保留原来的数值和节奏。

- 2026-11-17 用户试玩：保留已有的打空自动换弹，补齐切到空弹匣时立即开始换弹；换弹仍须完整耗时，不能靠反复切枪获得免费弹药。

爬行者巡逻、受引诱和追击时沿地面前进，贴地冲抓。步幅随实际位移变化，移动时四肢错峰承重，停下时四肢归位。

战斗提示跟随当前设备和准星目标。换弹进度从规则层的装填剩余时间读取；棉甲提示区分减伤和零伤害，盾冲提示横移；静电枪显示有效距离、松开放电及定身后的换枪时机。
