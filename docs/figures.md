# 手办造型：规则和检查记录

这两段原来写在 cine-engine 的 `docs/character-design.md` 和 `library/creatures/CASTCHECK.md` 里，内容是绒仔手办的，游戏拆出来时一起搬到这里。
通用的角色造型准则仍在引擎仓库的 `cine-engine/docs/character-design.md`。

## 从绒仔手办得到的造型规则

- **毛绒阵营的形状差异要来自身体**（绒仔 V5）：不能把同一具身体换帽子当成新角色。小头厚躯、收腹弓腿、低腹长臂、偏肩盾臂、团身短腿、瘦长驼背、沉肩巨臂、垂袋长颈，先脱离装备看剪影，再加道具。材质可以共用，头身网格和支撑结构分别做。
- 用户认可的角色是风格锚点。不能把「更可爱」自动解释为统一大头、腮红、亮眼和短背带裤；绒仔 V4 因此偏离原始针毡布偶。先保留其五官语汇、头身关系与材料，再调整其他成员的身体结构。
- **针毡质感要在实际镜头检查**（绒仔）：恒定布色、微法线、略不规则的填充表面、短纤维和轮廓绒毛共同构成质感。只把光滑球体设为高粗糙度仍会像塑料。禁止用大幅颜色噪声代替纤维，以免脸上产生杂色。
- 武器须有动作结构：投弹者要有载弹、持弹和抛投位置；弓手要有握弓手、搭箭点、可拉动的弦和箭。模型上的释放位置与规则层弹道起点一起核对，不能从胸口或头上凭空发射。
- 修订记录（2026-11-16）：绒仔僵尸 V4 被用户否定，V5 重做。明确风格锚点优先、毛绒阵营需要独立身体结构、针毡不能只靠粗糙度；补充投弹与弓箭的动作结构和发射点核对。

## 绒仔独立原生布偶检查 · V5 · 2026-11-16

本节为 Blender 原生资产，不修改下方《影刺》角色。用户否定 V4 的光滑圆润娃娃，也否定同体换装；当前以 V2 跳跳为锚点，去掉召唤巢，快跳/侧跳/扑扑合为跃行者，共九类。

- 原始跳跳：V2 网格、六关节边界与顶点色自动核对一致，保留纽扣眼、布口、缝补和细绒。未将 V4 亮眼/腮红/背带裤带入当前角色。
- 结构：其余八类独立建头身网格。检查正、35 度、侧、背和四向黑剪影；跃行者颈部、噬连兽肩部的初次空隙已补连，爬行者造型图按宽深重新取景。三张原生造型图见 `scenes/rongboy-mission/review/zombies-v5/native-sheet-{1,2,3}.png`。
- 个体定位：跃行者收腹弓腿；棉甲小头梨躯；爬行者低腹撑臂；持盾者偏肩长脸与大盾臂；炸弹客团身短腿与抛投手；弓手瘦长驼背与拉弦手；巨像沉肩巨臂；噬连兽垂袋头和长吸盘臂。
- 道具：炸弹有后背备弹、手持载荷和飞行/落地状态；弓有独立搭箭点、弦端点、拉弦点和软头箭。规则发射点与模型节点已对齐。中断/换场后的独立弦资源可释放。
- 实际镜头：九类近景均 ready=true、errors=[]、shaderErrors=0；真实键盘验证投弹、落地等待、横移无伤以及拉弓/放箭。截图与只读状态同在上述 review 目录。
- 边界：当前仍是视觉候选，未宣称用户认可；未宣称人工打通九类混战或完成平衡。原始 V1/V2 和被替代的 V3/V4 文件保留。
