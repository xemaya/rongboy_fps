# 布偶游乐园：准则

布偶游乐园是一关：十站连着走，每站办完一件事下一站的门才开，最后在马戏帐篷里打嬉笑小丑（2026-11-23 把原来的空园和直道那张"布偶游乐场"合成了这一关）。改之前先看这里，改完把学到的写回第 6 节。
全园概念图：`amusement-park-spiral.png`。出图交接单：`park-asset-handoff.md`。玩法总则：`fun-design.md`。

## 1. 一句话

**每个设施都能让你做一件事；办完这一站的事，路上的门才开，下一站才去得了；最后打小丑。**

没有收集、没有进度条（2026-11-23 用户："不需要集章卡这个机制"）。规矩是用户定的：**"所有的设施都具备，解密开启下一个设施，最后打boss小丑。"** 十站顺着小径排：入口 → 旋转木马 → 激流勇进 → 过山车 → 鬼屋 → 摩天轮 → 游戏摊街 → 碰碰车 → 镜子迷宫 → 马戏帐篷。

1.1 **每站的任务和清场条件写清楚。** 屏幕左上角一直写着这一站现在该干什么（"到码头按 F 登船，漂一圈"）。办完了，这一站的灯亮、门开，提示换成"门开了 · 沿小径去某某"。

| 站 | 设施任务 | 第一波出现时机 |
|---|---|---|
| 入口 | 冻住摇摆的门栓，再用手枪击碎 | 教学段 |
| 旋转木马 | 冻蒸汽阀，摇铃开动气浪 | 走过拱门后再向广场前进一段。第二波等木马首次启动 |
| 激流勇进 | 坐船或从码头放空船 | 回码头后 |
| 过山车 | 乘坐或发车，打亮两个轨道靶 | 回站后，先给落地的玩家一拍喘息 |
| 鬼屋 | 敲门进去，在门厅摇铃 | 摇铃后走回门廊外 |
| 摩天轮 | 坐吊舱一圈 | 下吊舱后 |
| 游戏摊街 | 任一摊位命中一次 | 记分后按 F 离开摊位 |
| 碰碰车 | 上车驾驶，按 F 下车 | 下车后 |
| 镜子迷宫 | 沿镜廊清场 | 进站后，三波分布在入口、镜廊和出口 |
| 马戏帐篷 | 清前场，打败小丑，拾取马达 | 进帐篷后，清完三波才播小丑登场 |

除售票口外，每站 10 只守卫，三波分别 3、3、4 只。先给约 0.85 秒提示，再实际生成第一波。上一波倒下且飞行中的攻击结束后留约 1.1 秒，下一波才出。清完本站并完成设施任务后放行。九站共 90 只普通守卫，Boss 单独接战。

1.2 **门只画眼前的两道**（要过的那道和刚过的那道），别的不画：远处的门看不清，白占开销。入口那道就是拱门，门栓夹在拱门上；最后一道是帐篷的门帘。

1.3 **倒下了从这一站的门口重来**，满血满弹，前面几站的门都开着、僵尸不回来；身上的血瓶和地上的东西回到进这一站时的样子。

1.4 **僵尸和人一样只走小径**，不踩草地、不穿设施。坐在设施上、站在摊位前的时候不挨打。

## 2. 互动

2.1 **一个键。** 走近设施，屏幕上出现"按 F ……"（手柄是 □），按一下。全园只有这一个互动键，和主游戏里"换脚边的枪"是同一个键：都是"对眼前这样东西做点什么"。

2.2 **提示要先于按键。** 进到 2.6 米内才出提示，提示里写的是会发生什么（"摇铃开动""上车""敲门"），不是设施的名字。正在运转、不能再按的时候提示消失，不留一个按了没反应的键。

2.3 **按下去马上有回应，然后演一段，演完回到原样。** 铃响、门开、车动都在按下的那一帧开始。每段 8–30 秒，演完设施回到等人的状态，可以再按。

2.4 **每个设施只有一种互动**，分四类：

| 类 | 设施 | 按键之后 |
|---|---|---|
| 看 | 旋转木马 | 设施演一段，人还站在路上，随时能走开 |
| 进 | 鬼屋 | 敲门，门开，走进门厅；在里面摇铃，幽灵出来（第 5c 节） |
| 坐 | 摩天轮、过山车、激流勇进 | 人被带着走一圈，中途可以再按一次跳过 |
| 开 | 碰碰车 | 人坐进车里自己开，随时按键下车 |
| 玩 | 三个游戏摊 | F 开局，方向键瞄准，空格投球，F 离开 |

入口和镜子迷宫没有可按的：直接走过去。

2.5 **怎么算打完**：小丑倒下后，在帐篷中央捡起高压马达，全园的灯亮起来，弹出结算。前面的设施玩几遍都行，办过的事不用再办。

2.6 **不罚人。** 没有时间限制。坐着的时候按跳过，回到上车的地方。

2.7 **摊位一局五颗毛球。** 打积木从底层击倒上层，打绒鸭要跟上移动，打气球逐个戳破。命中、扑空和剩下几球都在投球后有反馈。可以随时退出，重新进摊会清空本局记录。

## 3. 坐上去不晕（摩天轮、过山车、激流勇进）

晕的来源是眼睛看到自己在转、在加速，身体却没动。画面里的旋转比平移更容易晕，不是自己操纵的旋转比自己操纵的更容易晕。所以：

3.1 **镜头不滚转。** 过山车拐弯、俯冲时，地平线始终是平的。

3.2 **转向要慢、要匀；快放在直道和下坡上。** 过山车带着镜头转向的速度不超过每秒 45°。车在弯里能跑多快就由这条定：每秒 45° 配半径 4 米的弯，最快每秒 3 米多。所以想快不能靠把整圈调快，要靠轨道：直道和坡拉长，弯放在高处、车本来就慢的地方。车速不是匀的，由 `trackSchedule`（`scenes/rongboy-mission/track.js`）按轨道算：提升坡每秒 4.4 米，过了坡顶越低越快（最快约每秒 9.6 米），进弯前自己收速，出站进站缓起缓停。现在一圈约 98 米、24 秒，最高 10.6 米，最陡约 36°。

3.2a **弯要圆，控制点要匀。** 轨道的平面走向用直线加圆弧搭，控制点沿线等距（每 1.35 米一个），是算出来的，不手挪单个点。手摆的点弯里曲率忽大忽小，按 3.2 收速以后车会一顿一顿；两个控制点挨得太近曲线会打结。量弯有多急也要看前后各半米多，不看一小格。

3.2b **眼睛坐在车里，镜头俯仰跟坡度的七成。** 车随坡前倾后仰，眼睛的位置跟着车身走（沿轨道的法线抬高，不是笔直往上）。坡在 25° 以内时笔直往上看不出问题；到 36° 车身会转到眼睛的位置上，俯冲时眼睛钻进靠背里，整屏发黑。俯仰原来只跟一半；坡陡了以后只跟一半的话，爬坡时车身会抬到画面中间（违反 3.4），所以改成七成。激流勇进坡缓，仍是笔直往上、俯仰另设。

3.3 **起步和停下都缓。** 头两秒从零加到全速，最后两秒减到零。中间不突然变速。

3.4 **眼前有不动的东西。** 坐着的时候画面下方始终看得到自己的车头或吊舱栏杆。这是眼睛的参照物。它只在画面的下沿（吊舱另有顶沿压着上沿），不往中间长：给车、吊舱、围挡加装饰以后，要坐上去截一张图看有没有东西横进视线中间。坐着的时候眼睛在 1 米高，碰碰车的围挡不能高过 0.85 米。

3.5 **视线还在自己手里。** 坐着的时候照样可以用方向键转头看，转头是叠加在车的朝向上的。

3.6 **上下车用淡入淡出，不瞬移。** 约 0.4 秒黑一下。镜头从路上跳到座位上的那一下不让人看见。

3.7 **转得快的时候收窄视野边缘。** 画面四周压一圈暗角，转向越快越深，直行时没有。不改镜头的视角。

3.8 **随时能下。** 坐着的时候再按一次互动键，淡出回到上车的地方。

3.9 **开启「减少动态效果」时**：过山车与激流勇进从站台发车、从码头放船，玩家留在小径上。车、船回站后记下乘坐任务，并触发地面守卫。过山车的轨道靶也可在小径上处理。摩天轮照常（它只有很慢的平移）。

3.10 **摩天轮是最稳的一种坐法**：只有平移，每秒约 0.9 米，一圈 31 秒，镜头朝向完全由玩家自己定。

3.11 **激流勇进从码头登船**，沿缓坡和落水段转一圈，约 23 秒。沿用过山车的转向上限，俯仰更缓，镜头下沿能看到船头。

3.12 **打小丑时镜头自己上下看，只在两个时候。** 小丑战里两样东西不在一个高度：要塌的地砖和烟花落点在脚下，面具在弹簧盒把人弹到最高点时的平视高度。平视时最近只看得到 1.9 米外的地面（眼高 1.23 米、上下视角 65°），一块砖 2.35 米，脚下这块看不见；方向键每秒转 49°，低头再抬头要一秒半，而地砖只预警 1.55 秒。所以（用户 2026-11-23："惊喜盒子起来的时候要平视，地板消失的时候要从上向下俯视，所以视角要转换"）：地上有东西要躲的时候镜头自己低头 30°，过去了转回低头前的角度；被弹簧盒弹起来的时候镜头对着面具。规矩：只动俯仰、不动左右；每秒不超过 45°，快到的时候放慢；玩家自己上下看了（方向键、右摇杆，鼠标挪够 0.12 弧度）这一回就听玩家的；烟花后面紧跟着塌地砖，中间不抬头，一轮只低一次头。规则在 `amusement.js` 的 `clownGaze`。**这是镜头自己在动，用户容易晕：还没有人玩过，晕的话退路是镜头不动、让要塌的砖在平视高度也看得见（砖角立光柱）。**

3.13 **小丑登场五秒。** 门帘合上，灯串暗下；摇把连续响五下，盒盖在 1.72 秒弹开，小丑顺着弹簧伸展、回落，再歪头招手。镜头推近后在主动作时停住，最后退回玩家站位，露出正前方的安全惊喜盒。空格或开火键可立即跳过，按下跳过的那一枪不消耗弹药；完整观看和跳过都从相同位置接战。减少动态效果时使用固定机位。开发预览可用 `?level=amusement&debug=1&preview=clown-intro`，按回车播放。

## 4. 走路

4.1 人只能走在缝线小径上、马戏团里和各设施门口的小平台上。路以外是给眼睛看的。

4.2 提示出现的位置都在路上，不用离开路去够。

进马戏团和看演出期间，移动和视角都由玩家控制。小径边缘与墙体一起判断目标位置，松键时不运行会把角色推离墙面的碰撞修正。

4.3 **看着是实心的东西就走不进去。** 入口只能从拱门底下过（两座塔楼和售票亭各有一个碰撞盒）；木马的圆底座用三个盒子叠成八边形挡住，台阶另加一个。以后给设施加大件的时候同样要补盒子，测试里有一条专门走一遍。

## 5. 布景

5.1 **照概念图做，认得出是哪一个。** 每个设施先对上轮廓和主色（木马是赭黄和青、过山车是珊瑚红和金、鬼屋是紫、马戏团是红白），再加细节。

5.2 **会动的部件单独成组**，不动的按设施分块（第 5d 节）。开销每一轮都量，数字记在 5d.6。

5.3 **从路上看得到的那一面做细**，背面可以简单。人走不到设施背后。

5.4 **字都用代码写**（要切换中英文），贴图上不带字。园区招牌用本地圆体，等园区字形加载好再绘制 Canvas 纹理，长英文按字号等比例缩小。

5.5 **设施之间用围栏、灯串、花坛连起来**，不要只是草地上摆着十样东西。

5.6 **照参考图借样子，不借走向。** `docs/park-refs/` 里每个设施一张参考图。轮廓、配色、装饰照它做；但凡是和"能走、能坐、不晕"冲突的地方听规则的：过山车参考图上有个又高又陡的大拱，轨道不照它的陡度做（现在最陡 36°，镜头转向仍守 3.2）；摩天轮参考图是 8 个吊舱，游戏里是 10 个（规则和测试按 10 个写的）；碰碰车场参考图是圆的，游戏里是椭圆（旁边就是小径，放不下圆的）。

5.7 **画出来的图只当平面用**：海报牌、哈哈镜、摊位招牌上的图标、鬼屋的肖像。它们是一张贴在板子上的图，不拿来代替立体的布景。

5.8 **哈哈镜放在迎面的位置。** 迷宫里人是被路带着走的，镜子放在每一段路正对着的那块镜板上（进门正前方、拐弯前正前方），不放在身侧。

## 5d. 精细度：做到第一关的水平，开销不超过第一关

第一关（家的花园）是标尺。它看着细，是因为下面五条，不是因为面数多。

5d.1 **一样东西由它真有的零件拼成。** 木马有头、脖子、四条腿、鬃毛、尾巴、耳朵、眼睛、鞍垫、肚带、笼头、缰绳，不是三个球加四根棍。树是树干加一层层往外垂的大叶片，不是一个球。先问"真的这样东西有哪些零件"，再动手。

5d.2 **每个交接处都收边。** 两块布相接的地方有滚边、扇贝边、布箍或者一行针脚：伞沿、塔顶、台面边缘、路边。没有收边的交接看着就是两个方块插在一起。针脚是最便宜的收边（一针 12 个三角形），每条缝、每个边缘都可以加。

5d.3 **圆的东西要圆。** 半径超过 1 米的圆盘、圆柱至少 48 边，否则轮廓上看得出棱。伞面每片布横着再分 3 格。

5d.4 **料子按距离选。** 毛巾绒（terry）最像参考图的羊毛毡，用在离人 2 米以外的大面上（塔身、伞面、底座、小径）；贴近到 1.5 米以内它的毛圈会放大成一片花斑，所以台阶、标记柱这些会走到跟前的用针织（knit）或毛毡（felt）。绗缝（quilt）的菱形格又大又规整，不用在大面上。木头的东西用木板（boards）。

5d.5 **地面要有东西。** 小径两边有鼓起来的滚边，中间一行深绿的虚线；路边交替放石头、灌木、花丛，贴着路沿有草丛；园子四周一圈树把园外挡住。

5d.6 **开销的预算和做法。** 上限是第一关：站在花园里 367 次绘制、约 109 万个三角形。游乐园的布景任何位置不超过 **300 次绘制、70 万个三角形**（这是空园时定的数；合成一关以后手里多了枪、路上多了门和僵尸，实测见本节末尾，仍在第一关以下）。量法：开发页的 `__rb.render()` 返回 `calls` 和 `tris`，在入口、木马、往中心看、鬼屋、摩天轮各站一次。

| 做法 | 省在哪 |
|---|---|
| 不动的布景按设施分块；路边的树、石头、灯柱按六大块分 | 背后的整块不画。以前全园并成一块，朝哪看都是 43 万个三角形 |
| 每块两层：主体（投影）和小装饰（针脚、花、穗子、草丛；不投影） | 小装饰离人超过 26 米整层关掉，那时它们不到一个像素；阴影那一趟也不画它们 |
| 倒圆角的方块，最短边不到 0.35 米的圆角只切一刀 | 108 个三角形，不是 300 个 |
| 同一种零件只用几种布料 | 每块里一种布料一次绘制，多一种料全园多十几次 |
| 发光的小灯并成一组 | 摩天轮轮圈上 20 个灯原来是 20 次绘制，现在 1 次；马戏团的 32 个灯并成四组（开演时一组一组地闪，改亮度不改大小） |
| 镜子迷宫的镜板并成一组 | 原来一块镜板一次绘制，四十多次，现在 1 次 |

通用零件都在 `scenes/rongboy-mission/park-kit.js`（针脚、扇贝边、穗子、花饰、栏杆、叶片树、松树、灌木、花丛、石头、草丛、灯柱、长椅、木马）。新设施先用这些拼，不够再加。

各轮量到的数：

| 时间 | 入口 | 木马前 | 往中心看 | 鬼屋前 | 摩天轮前 |
|---|---|---|---|---|---|
| 细化前（1993f62） | 179 次 / 50 万 | 51 / 44 万 | 109 / 45 万 | 178 / 45 万 | 170 / 43 万 |
| 样板：入口 + 木马 + 通用件 | 231 / 49 万 | 207 / 44 万 | 279 / 45 万 | 244 / 42 万 | 206 / 33 万 |

## 5c. 鬼屋：能走进去

5c.1 **两步，每步还是那一个键。** 在门廊按一下是"敲门"，门往里开；走进门厅，在尽头的小桌前再按一下是"摇桌上的小铃"，幽灵这时候才出来。

5c.2 **门不会把人关在里面。** 敲过以后门一直开着，人离门 11 米以外才关；门厅里任何位置离门都不到 6 米。关上以后可以再敲。

5c.3 **不吓人。** 没有突然的声音和突然贴脸的东西。幽灵从肖像上面的墙里慢慢飘出来（一只接一只，间隔 0.7 秒，出来用 0.9 秒），停在墙边晃，8 秒后退回去。离人最近也有 1 米多。

5c.4 **门厅的地面和外面一样高**，没有台阶，直接走进去。屋里能走的范围比墙往里收 0.4 米，家具前面也留出来，镜头不会贴到东西上。

5c.5 **屋子不是一个实心块。** 墙是一圈薄墙，前墙留门洞，所以从门外就看得见里面的灯和画。进不进得去由规则管（`park-tour-layout.js` 的 `HAUNT`）：门关着的时候屋子占的那块地整块进不去，门开了只有门洞和门厅能走。

5c.6 **门厅里有什么**（照 `docs/park-refs/ref-05-haunt.png` 右下那一格）：木地板、圆地毯、护墙板、门里两边的帘子、一盏吊灯、西墙的书架、后墙三张肖像、肖像下的小桌（蜡烛和小铃）。
