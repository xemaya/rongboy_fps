# 一颗毛球惹的祸 · 搁置的片头试验

用户未采用本次视觉效果，现归档为独立实验，游戏菜单不展示片头入口。

AI流程源码、提示词和回执位于 `assets/rongboy/intro-ai-v1/`。生成图片、视频和环境快照仍在本地，不纳入Git；详情见该目录 README。`ai/QA.md` 仅记录本次初剪的技术检查和已知限制。
