# 绒仔 FPS 长期打磨计划

2026-11-19 · 讨论稿。下面的关卡改法和首领归属是候选设计。轮次按依赖排序，一轮可以跨几次迭代，试玩过关才往下走。

## 我们想做成什么体验

玩家推开玩具屋的门，能先看出房间里最大的麻烦，再利用毛球、布偶或家具做一件聪明的事。理想的一场遭遇是：持盾者堵在桌边，玩家从盾沿看出正面难打，故意把毛球打到旁边的墙，听见回弹，看到它从背后挨了一下。下一间房，即使没有提示，玩家也会主动找可以借的墙。直射、绕后和手枪蓄力都应能解决这道题；发现回弹给人的是额外的乐趣。

以这个片段作为判断标准。准星上写清了“绕后打”能解决困惑；玩家亲自发现绕哪个方向、为什么这一枪漂亮，才值得把这间房复制给更多人。

## 起点

- 主创试玩感受：展现约 8 分；僵尸和 Boss 约 5–6 分；武器和操作约 5 分；氛围短板最明显。这是排优先级的起点，不再给尚未试玩的部分打分。
- 四张正式地图中，家是拿篮子撤离，博物馆是取回三件展品，学校和奶奶家是清场。编译后的敌人配置里，只有家的阁楼放了守墓巨像。噬连兽已有模型、吸引规则和独立试战。
- 七种普通角色与两种 Boss 已有定稿或修订过的样板。正式关卡默认载入 V7 模型库，三个 study 入口分别载入专用模型库。需要把选定版本在正式关卡逐只接入，复查受击体、出手点、遮挡及帧时间。
- 游戏有枪声、命中、机关等程序音效，片头也有配乐。玩家感到“没有声音”是真实体验。第一步要在实际设备听一遍：键盘首进、纯手柄首进、暂停恢复、标签页切回分别是否出声，再区分播放问题与声场过薄。战斗中还需要可持续的环境声和音乐层次。
- 键盘、PS5 手柄和战斗 HUD 都已有实现。最近遇到的换弹看不见、棉甲与盾冲分不清、静电枪不会用，是第一轮的回归场景。

## 工作全貌

| 工作面 | 具体要打磨的东西 | 试玩时看什么 |
|---|---|---|
| 输入、枪感、毛球 | 转向和微调、按下与松手的时机、点射与蓄力的代价、后坐回稳、反弹轨迹、装填反馈。键盘和手柄分别调。 | 同一个目标，第二枪能否凭第一枪的反馈主动修正？故意借墙的一球，能否跟到命中？ |
| 武器选择与资源 | 固定手枪、第二枪、手雷各自的用途；掉枪摆位、可用弹量、换弹窗口。静电枪的价值由它替下一枪争取的时间决定。 | 玩家会在看到威胁后主动换枪，还是只在弹匣空了才换？换上的武器有没有解决问题？ |
| 普通敌人与 AI | 每种先定一个可读动作、一项威胁和一个可利用的破绽，再调血量、速度、转身和硬直。混战要排出手先后。 | 棉甲背后真的有时间可绕？持盾者冲过头能否被反打？挨箭前能否找到弓手？ |
| 房间与遭遇编排 | 入口视线、能借弹的墙、掩体两侧的路线、枪和机关出现的时机。单独认识敌人，然后两种合用，最后给一段喘息。 | 玩家进门第一眼看哪里？站门外一直打是不是最优解？有没有两种都说得通的过法？ |
| 每关高潮与 Boss | 每张图有自己的结尾。Boss 检查本关教过的动作；可以击败、摆脱或边对抗边交付目标。 | 玩家能否说出这一关结尾和上一关哪里不同？第一次失败后知道第二次要试什么？ |
| 操作教学、失败与重试 | 在安全距离先让玩家试一次，提示随当前使用的键盘或手柄切换。明确受击来源、破防成功和撤离方向。高难遭遇前安排可重试起点。 | 关掉口头讲解，第一次玩的人能否自己放电追击、躲盾冲？失败后多久能再尝试刚才那一步？ |
| 视觉、物理与材质 | 优先修“看见能过却过不去、看见能挡却挨打、击中了却看不清”。毛毡、针脚、绒絮、布景反应服务于距离、材质和命中判断。 | 同一张桌子挡人、挡球、遮视线是否符合直觉？绒絮散开时还能否看见下一次攻击？ |
| 开场、声音与氛围 | 从第一人称可操作的短开场进入世界；建立房间底噪、方向性敌声、武器近声、音乐起伏和战后留白。同步保留快速选图和重玩入口。 | 戴耳机能否听出威胁从哪来？安静与危险能否区分？静音后关键预警是否依然可见？ |
| 通关动机与重玩 | 主线给轻度玩家清楚的完成感；用隐蔽路线、机关或反弹巧解给熟练玩家第二种目标。复盘展示一件本局做得漂亮的事。 | 打完会记住哪一枪或哪个房间？愿不愿再开一次，换一种打法？ |
| 贯穿全程的稳定性 | 实际 MacBook 上检查首次加载、帧时间尖峰、输入切换和镜头舒适度；同时核对正式入口与样板资产版本。 | 同一段战斗里，掉帧、声音失效、穿模或镜头晃动有没有让玩家误判？ |

## 建议推进顺序

| 轮次 | 本轮交付 | 进入下一轮的依据 |
|---|---|---|
| 0 · 留基线 | 固定一个现有关卡入口和版本，录从进门到第一次交火的 3 分钟。用键盘和手柄各跑一遍，记下首次没看懂、首次打爽和首次想退出的位置。核查出声与帧时间。 | 有可重玩的旧版和可比的新入口；核心问题能指到具体一枪或一间房。 |
| 1 · 一把枪、一间房 | 首选家的花园入口做独立样板。一把线轴手枪、一面可借弹的墙、一只跳跳、一只持盾者。打通点射、蓄力、盾挡、绕后/反弹、装填这一小段；一起调球速、冲量、布偶反应、音画时机。 | 不看策划说明能识别装填与挡弹；能复现一次主动破盾或借墙命中；同场 A/B 后玩家能说出想再试的一种打法。 |
| 2 · 枪和敌人配对 | 扩成三场 30–60 秒遭遇，先试霰弹对跃行者、静电控群后换枪、毛衣针对棉甲。记录有效距离、击倒所需命中、打断窗口和失误代价，再铺到其他武器。 | 每种枪都有至少一个值得主动选它的局面；普通敌人仍能用保底手枪处理。 |
| 3 · 一整关的节奏 | 打磨“家”从院门到阁楼再撤离的完整路径。首遇教学、闹钟解法、补给、短暂停歇和巨像现身串起来。加入这一关的环境底声、战斗起落与撤离提示。 | 新玩家能自己拿篮子并找到出路；能复述一次聪明解法和一个紧张瞬间。 |
| 4 · 四关四个高潮 | 按下表顺序做灰盒，每次只新增一个 Boss 遭遇。先验证玩法，再投入定妆、动作、特效和配乐。 | 四关各有辨识度，Boss 各有提前可学的反制、清楚的破绽、合理的重试距离。 |
| 5 · 开场与全局声音 | 把验证过的手感、场景和音乐串成正式入口。例如玩家在绒仔手里看到半截线头，亲手装进线轴、打一球让布铃响，门后传来第一只僵尸的脚步。保留跳过/直接重玩。 | 第一次可操作时就知道“我是谁、手上是什么、门后有什么”；重复游玩能迅速进场。 |
| 6 · 整体收口 | 依完整通关录像修难度峰值、遮挡、混音、重复提示、加载与帧时间；收掉样板/正式版差异，复查四关和两种输入。 | 连续通关后，玩家能说出最喜欢的一关、最想再用的一把枪，以及愿意重玩的理由。 |

声音从第 1 轮就参与枪感，第 3 轮就参与关卡。第 5 轮处理完整开场和跨关的一致性。展现已有较好的基础，影响读招与碰撞的视觉问题在对应轮次立即处理，其余细节在收口时集中打磨。

## 四关的 Boss 方向（提案）

| 地图 | 终场提案 | 先验证的问题 |
|---|---|---|
| 家 · 阁楼 | 沿用守墓巨像。拿篮子触发现身，重拳震动阁楼，玩家可以趁它收拳撤离，也可以挑战它。 | 原任务是拿了就跑，门口、楼梯与音画是否让人看懂退路？ |
| 博物馆 · 展厅 | 试用噬连兽守最后的交付区。展柜可切断牵引，聚光灯提供一次换位或搬运展品的机会。 | 吸引方向和遮挡足够清楚吗？搬运目标是否仍然重要？ |
| 学校 · 操场 | 新 Boss 候选为“队长布偶”：先示范一次直线冲撞，再在场地上划第二条冲线；躲开后可诱它冲进颜料区，露出破绽。 | 玩家能否把前面学的横移、打颜料桶变成一次主动反击？ |
| 奶奶家 · 菜园 | 新 Boss 候选为“线团看园人”：沿菜畦巡走，被闹钟引向岔路，转身时露出背后的线结。最后一球可从畦边木板反弹过去。 | 单靠小院、障碍物和转身动作，能否做出和操场完全不同的打法？ |

## 第一轮怎么一起验收

1. 同一间房、同样的出生位置和弹量。先让玩家自然打；第二次交换新旧顺序，再用另一种输入。不要提前说墙可以借弹。
2. 只记四件事：第一次发现正面挡弹的时刻；装填时是否误以为按键失灵；是否主动改变站位或射角；清完后是否自发再试一次。保留一句玩家原话。
3. 若玩家说“看懂了但不想再打”，继续改命中、蓄力收益或房间摆位。若只靠提示文字才懂，先改敌人动作和命中表现。若只有手柄或键盘其中一个难受，单独调输入。
4. 每轮留下旧/新试玩入口、改了什么、自动回归结果、实际设备与试玩判断，由项目负责人决定保留、再迭代或退回。行为数据用于定位问题；“好不好玩”由人来判断。

### 第 1 轮样板 · 花园里的一面墙

本地试玩：`rongboy-play.html?level=garden-wall&feel=new`。右上角可以从相同初始状态切换原手感（`feel=base`）。两版均提供一把线轴手枪、相同的 6 发初始弹匣、同一块墙和两只已定稿敌人。第一次试玩时不预告解法，按 Enter 或手柄 ✕ 开始。

新版增加蓄力达标的音画提示、盾臂受力回弹和破防侧摆、根据真实飞行路径绘制的短拖线，以及木板与回弹命中的声音。结算分别记录正面挡弹、蓄力破盾和借墙打背。最后一项只计直接从指定木板折返、命中持盾者背面且造成伤害的毛球。

规则测试已覆盖正面点射、蓄力和三个开枪时刻的反弹路径。浏览器纯键盘试玩已打出三种结果。实体手柄手感、首次自然发现解法的过程，以及是否想重玩，留给本轮人工 A/B 试玩判断。第一次记录：版本 ___，设备 ___，最想再打一遍的瞬间 ___，最不明白的一下 ___。
