# 绒仔 · 开始界面与操作路径

2026-11-19 · 全屏界面概念。主界面沿用 A 的第一人称院门，选关页沿用 C 的场景预览和横排关卡卡片。

| 画面 | 进入方式 | 确认与返回 |
|---|---|---|
| [01 主菜单](01-main.png) | 打开游戏 | 上下选「选关、设置、练习、图鉴」，Enter / ✕ 打开选中的页面。 |
| [02 选关](02-chapters.png) | 主菜单 → 选关 | 左右切换家、博物馆、学校、奶奶家，预览和任务说明一起换。确认才加载关卡，Esc / ○ 回主菜单。 |
| [03 关卡加载](03-loading.png) | 选关 → 确认进入博物馆 | 用所选关卡的画面承接加载。就绪后进入第一人称游戏。 |
| [04 关卡暂停](04-mission-pause.png) | 正式关卡 → 暂停 | 继续、重玩本关或返回选关。关卡结束也可重玩或返回选关，回到原先选中的地图。 |
| [05 设置](05-settings.png) | 主菜单 → 设置 | 上下选项目，左右调值，返回保留选择。「查看按键」可在键盘和手柄之间切换。 |
| [10 按键](10-controls.png) | 设置 → 查看按键 | 左右切换键盘和手柄说明，Esc / ○ 回设置。 |
| [06 练习](06-practice.png) | 主菜单 → 练习 | 「花园练习」直接进入花园准备画面。「兵种试战」先进入敌人选择。Esc / ○ 回主菜单。 |
| [11 兵种试战](11-practice-enemy.png) | 练习 → 兵种试战 | 上下选敌人，确认进入该敌人的准备画面。Esc / ○ 回练习选择。 |
| [07 练习就绪](07-practice-ready.png) | 练习 → 确认 | 等玩家按 Enter / ✕ 才接敌。重开回到就绪画面，从准备画面或暂停页退出回原来选择练习的页面。 |
| [08 图鉴列表](08-codex-list.png) | 主菜单 → 图鉴 | 上下浏览，右侧换成选中的模型。确认打开详情，Esc / ○ 回主菜单。 |
| [09 图鉴详情](09-codex-detail.png) | 图鉴 → 确认所选敌人 | 看模型、读招式和反制。可直接试战，练完返回该敌人的详情。Esc / ○ 回图鉴列表并保留选中的敌人。 |

## 共用操作

- 主菜单上下选择。Enter / ✕ 确认，Esc / ○ 回上一层。切换焦点会立即更新预览，确认进入关卡时才加载。
- 返回时恢复刚才的焦点。正式关卡回选关，普通练习回练习选择，从图鉴发起的试战回图鉴详情。
- 图鉴详情的正、侧、背三档共用一个页面。单兵种与花园练习复用就绪画面的布局。
- 图鉴和试战列表的小图仅作排版参考，制作时从定稿模型生成头像。
- 设置页显示功能提案。概念图上的材质、排版和道具以设计参考为准，正式界面复用项目现有角色、模型和控制键。
